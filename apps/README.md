# Apps (Noah's Ark)
- `operator-dashboard/` (**Ark Command**): live map, SOS queue, AI dispatch copilot, mission control (GDEX / relief / military modes)
- `maintainer-dashboard/` (**Ark Care**): fleet health, predictive maintenance alerts, AI maintenance assistant, work orders
- `sos-mobile/` (**Ark SOS**): help requests (text, voice, photo, location), drone ETA, AI safety chat; SMS/WhatsApp fallback
