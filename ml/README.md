# ML models
- `water-landing-classifier/`: safe landing surface detection (SageMaker -> edge)
- `sensor-fusion/`: rain-robust perception weighting
- `predictive-maintenance/`: motor/battery/seal anomaly detection from telemetry
- `flood-demand-forecast/`: predict where relief will be needed (rainfall, river levels, history)
- `datasets/`: dataset manifests (raw data is git-ignored)
